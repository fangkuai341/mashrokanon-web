# 白菜的森林 · 原型说明（v0.5）

真白花音「后日谈」纪念网站的**可运行原型**，对应 PRD（`../PRD-后日谈纪念网站.md`）V1.0/V1.1 的核心页面。

## 如何预览

**方式一：本地服务器（推荐）**
```bash
cd prototype
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/
```

**方式二：直接双击** `index.html`（哈希路由在 file:// 下也可用）。

## 包含的页面

| 路由 | 页面 | 对应 PRD 模块 |
|---|---|---|
| `#/home` | 首页（森林入口、倒计时、统计、入口卡片、毕业公告节选） | — |
| `#/timeline` | 足迹时间轴（2019–2026，按年筛选） | 模块 A |
| `#/memory` | 记忆墙（写信、标签筛选、排序、点灯） | 模块 B |
| `#/capsule` | 时光胶囊（埋胶囊、锁定/开启、倒计时） | 模块 D |
| `#/rank` | 贡献榜（前三名领奖台 + 完整榜单） | — |
| `#/about` | 关于本站（非官方声明、维护信息） | — |

## 已实现的原型能力

- **中 / 日双语切换**（右上角），UI 文案随语言切换，时间轴/留言等内容为中文（日语字段已预留在数据中）
- **路由切换**：hash 路由，刷新不丢失当前页
- **记忆墙**：写信 → 以「审核中」状态上墙（演示自动过滤流程）；点赞（点灯）计数
- **足迹外链**：时间轴每张卡片带「在 B 站查看」按钮（demo 跳转到对应关键词的 B 站搜索页）
- **贡献榜**：前三名领奖台（冠军高亮）+ 完整榜单，替换了原投稿中心页
- **时光胶囊**：写入的信封存在 `localStorage`，带开启倒计时；2027-05-01 的演示胶囊为「已开启」
- **首页倒计时**：动态计算距毕业百日祭（2026-08-09）天数，过期自动切到毕业一周年（2027-05-01）
- **视觉**：森林月光主题（暗紫夜空、星、萤火、灯海、纸信），移动端优先，支持「减弱动画」

## 演示数据说明

时间轴事件、记忆墙来信、胶囊、贡献榜均为**原型演示内容**（基于公开资料整理，已标注「演示」），
正式上线前需按 PRD 流程替换为经审核的真实内容。留言/胶囊当前存于浏览器 `localStorage`，
正式版按 PRD 使用国内云 Serverless + 数据库存储。
